# 🎮 Mini Game Project – Tic Tac Toe

A simple console-based Tic Tac Toe game developed using C++.  
This project demonstrates core programming concepts such as loops, arrays, functions, and conditional statements through an interactive game.

- Two-player Tic Tac Toe game
- Dynamic game board display

# 📖 Game Rules

- The game is played between two players.
- Player 1 uses **X**
- Player 2 uses **O**
- Players take turns choosing positions on the board.
- The first player to align 3 symbols horizontally, vertically, or diagonally wins.
- If all positions are filled without a winner, the game ends in a draw.
